# 久坐提醒 sit-reminder

一个 Windows 桌面久坐提醒小工具：在**你指定的时间段内**，按**可自定义的间隔**提醒你起身活动，支持 **Windows 系统通知 + 置顶弹窗 + 提示音**，并常驻**系统托盘**。

## 功能

- **多个提醒时段**：只在设定的时段内提醒（例如 09:00-12:00、14:00-18:00），时段外自动暂停计时。
- **提醒严格对齐时段起点**：提醒时间为「时段起点 + N × 间隔」（如 09:00 开始、间隔 45 分钟 → 09:45、10:30、11:15…）；程序在时段中途启动时，倒计时自动对齐到下一个整点。
- **可自定义提醒间隔**：默认 45 分钟，1-600 分钟可调。
- **提醒后自动休息**：每次提醒后进入休息状态（默认 3 分钟，可调），休息期间不计久坐，倒计时显示休息剩余。
- **三种提醒方式**（可分别开关）：
  - Windows 系统通知（Toast，失败时回退为托盘气泡）
  - 置顶弹窗窗口（「我起来了」/「稍后提醒」）
  - 提示音
- **我起来了**：先休息，再从零计满一个间隔。
- **稍后提醒**：弹窗可延后 N 分钟再提醒，到点提醒后恢复正常节奏。
- **测试提醒不影响真实倒计时**：测试仅预览效果，不会重置或改变下次提醒时间。
- **开机自启动**：可选开机后自动后台运行（写入注册表 Run 键，无需管理员权限）。
- **系统托盘常驻**：菜单可显示主界面、暂停/恢复、测试提醒、退出；托盘悬停显示下次提醒倒计时。
- **单实例运行**，避免重复启动。
- 配置保存在 `%APPDATA%\SitReminder\config.json`。

## 运行环境

- Windows 10/11
- Python 3.10+（开发时使用 3.12）

## 从源码运行

```bat
python -m pip install -r requirements.txt
python main.py
```

程序默认最小化到托盘，双击托盘图标或右键「显示主界面」打开设置。

## 打包为 exe

```bat
build.bat
```

或手动：

```bat
python tools\make_assets.py
python -m PyInstaller --clean --noconfirm build.spec
```

产物：`dist\SitReminder.exe`（单文件、无控制台窗口，双击即用）。

## 使用说明

1. 打开主界面，在「提醒设置」中设定提醒间隔、稍后提醒时长、默认休息时长。
2. 在「提醒时段」中添加/删除时段（开始时间须早于结束时间）。
3. 勾选需要的「提醒方式」。
4. 在「系统」中按需勾选「开机自动启动」「启动时最小化到托盘」。
5. 点击「保存」应用设置。
6. 用「测试提醒」验证通知、弹窗与提示音是否正常（不影响真实倒计时）。

## 提醒节奏说明

设时段 09:00-12:00、间隔 45 分钟、休息 3 分钟：

```
09:00 ────────── 久坐 45 分 ────────── 09:45  提醒
09:45 ─ 休息 3 分 ─ 09:48 ───── 久坐 42 分 ───── 10:30  提醒
10:30 ─ 休息 3 分 ─ 10:33 ───── 久坐 42 分 ───── 11:15  提醒
```

- 提醒时刻始终对齐时段起点（09:45、10:30、11:15…）。
- 点「我起来了」：立即休息 3 分钟，休息结束再从零计满 45 分钟（以此刻为新起点）。
- 点「稍后提醒」：延后 N 分钟，到点提醒后恢复正常节奏。

## 项目结构

```
├─ main.py              入口：单实例、加载配置、启动托盘与计时
├─ app/
│  ├─ config.py         配置模型与 JSON 读写（存 %APPDATA%）
│  ├─ scheduler.py      时段判定与久坐计时（纯逻辑，可单测）
│  ├─ notifier.py       统一提醒：Toast + 弹窗 + 声音
│  ├─ popup.py          置顶提醒弹窗
│  ├─ tray.py           系统托盘图标与菜单
│  ├─ main_window.py    主设置窗口
│  ├─ style.py          全局样式表（QSS）
│  ├─ autostart.py      开机自启动（注册表 Run 键）
│  └─ resources.py      资源与路径解析（兼容打包）
├─ tools/make_assets.py 生成图标与提示音
├─ tests/test_scheduler.py 单元测试
├─ build.spec / build.bat  PyInstaller 打包
└─ requirements.txt
```

## 说明与限制

- 不支持跨零点时段（如 22:00-06:00），开始时间必须早于结束时间。
- 暂不包含“鼠标键盘空闲检测”（离开自动暂停）。
- 程序仅本地运行，不联网、不收集任何数据。
